Google Apps Script V8 Ecosystem

LYGUA

Leverage Your Google User Account into high-performance serverless computing, hardware cryptography, and modern toolchains.

@lygua/crypto

W3C Web Cryptography API implementation with SHA-1, SHA-256, SHA-512, MD5, and quota protection.

@lygua/secure-random

Pure CSPRNG entropy extracted directly from Google's backend SecureRandom hardware engine.

@lygua/utils

Intelligent deep cloning with AccessorMode, prototype hardening, deep equality, deep merge, and private stores.

@lygua/client

Type-safe, Promise-based RPC client for google.script.run with transparent local mock development.

@lygua/testing

In-memory test doubles and offline fakes for PropertiesService, CacheService, and Utilities.

lygua (Monolith)

Zero-dependency standalone IIFE bundle (lygua.iife.js) dropping directly into Google Apps Script as a .gs file.
